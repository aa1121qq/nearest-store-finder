# أقرب مخزن إليك — Nearest Store Finder (نموذج تجريبي كامل)

نموذج أولي (Prototype) يحاكي **التدفّق الكامل** للعميل عبر صفحتين:
1. **الصفحة الرئيسية** — يحدّد موقعه ويُحسب أقرب مخزن.
2. **صفحة الـ Checkout** — يظهر المخزن تلقائياً (auto-fill) ويُدخل رمز العنوان الوطني (محاكاة سبل).

> **الهدف:** إثبات أن المنطق صحيح قبل النقل إلى **Magento**.

---

## النقطة الجوهرية المراد إثباتها

> **المخزن يُحسب مرة واحدة من إحداثيات العميل عبر Haversine، ويُمرَّر كما هو بين الصفحتين. العنوان النصي (سبل) منفصل تماماً ولا يؤثّر على اختيار المخزن. لذلك التطابق بين الصفحتين مضمون: نفس الإحداثية = نفس المخزن دائماً.**

---

## التدفّق الكامل

```
[index.html]                              [checkout.html]
─────────────                            ─────────────────
1. زر "حدّد موقعي"                       1. اقرأ المخزن المحفوظ
2. Geolocation → lat/lng                 2. اعرض: "سيتم التوصيل من X"
3. Haversine → أقرب مخزن                 3. حقل "رمز العنوان الوطني"
4. عرض النتيجة                           4. محاكاة سبل → عنوان نصي
5. حفظ في sessionStorage  ─────────→     5. الملخّص النهائي + تأكيد
6. زر "متابعة للدفع"
```

---

## المميزات

- **بدون أي API مدفوع** — لا Google Maps، لا خدمات خارجية.
- **Geolocation API + معادلة Haversine** — حساب محلي.
- **Vanilla JS** فقط، بدون مكتبات أو خطوة بناء.
- **واجهة عربية RTL** متجاوبة على الجوال.
- **خطة بديلة (Fallback)** في كل صفحة عند رفض إذن الموقع.
- **منطق التوفّر الذكي**: المنتجات تُعرض كـ "متوفر" إذا كان أقرب مخزن ضمن **15 كم**.
- **محاكاة سبل** — تتحقّق من نمط الرمز (4 أحرف + 4 أرقام) وتعيد عنواناً وهمياً.

## نقاط المحاكاة الواضحة (و كيفية استبدالها في Magento)

كل ما هو **محاكاة** علّقنا عليه في الكود بوضوح. هنا الخريطة الكاملة لنقاط الاستبدال:

| في النموذج (محاكاة)                       | في Magento الحقيقي                                       |
|------------------------------------------|----------------------------------------------------------|
| `const stores = [...]` في `app.js`        | بيانات من قاعدة بيانات Magento (50+ مخزن حقيقي).         |
| `sessionStorage` لتمرير الاختيار           | `Customer Session` أو `Quote` على الـ backend.           |
| `simulateSebl(code)` يعيد عنواناً وهمياً    | استدعاء API سبل الفعلي + تخزين العنوان على الـ Customer. |
| `alert("تم تأكيد الطلب")`                  | إنشاء **Order** فعلي عبر Magento Order API.              |

> **المهم:** المنطق الحقيقي (`haversineKm`, `findRankedStores`) لا يتغيّر — فقط مصادر البيانات.

## محاكاة سبل — كيف تعمل

- نمط الرمز المقبول: **4 أحرف لاتينية + 4 أرقام** (مثال: `RRRD2929`).
- إذا كان الرمز صحيحاً: نُولّد عنواناً وهمياً ثابتاً مشتقاً من حروف وأرقام الرمز (نفس الرمز = نفس العنوان دائماً).
- إذا كان غير صحيح: تظهر رسالة خطأ.

> هذه محاكاة بصرية فقط — لا اتصال بأي خدمة خارجية.
