# أقرب مخزن إليك — Nearest Store Finder

نموذج أولي (Prototype) لصفحة ويب تحدّد موقع العميل عبر المتصفّح، ثم تحسب أقرب مخزن له من قائمة مخازن باستخدام معادلة **Haversine**، وتعرض النتيجة.

> الهدف: اختبار الفكرة قبل دمجها لاحقاً في متجر **Magento**.

---

## المميزات

- **بدون أي API مدفوع** — لا Google Maps، لا خدمات خارجية.
- **Geolocation API** المدمج في المتصفّح (مجاني).
- **معادلة Haversine** لحساب المسافة محلياً.
- **ملف واحد** فقط: `index.html` (HTML + CSS + JavaScript خالص).
- **بدون مكتبات أو build step** — يعمل بفتح الملف مباشرة.
- **واجهة عربية RTL** متجاوبة على الجوال.
- **خطة بديلة (Fallback)**: قائمة منسدلة لاختيار المنطقة يدوياً إذا رفض المستخدم إذن الموقع.

---

## كيف يعمل

1. يضغط العميل زر **"حدّد موقعي تلقائياً"** (أو على شريط "يشحن إلى" في الأعلى).
2. المتصفّح يطلب إذن الوصول إلى الموقع.
3. عند الموافقة: يحصل التطبيق على إحداثيات `lat/lng` للعميل.
4. تُحسب المسافة بمعادلة Haversine بين العميل وكل مخزن في القائمة.
5. تُرتّب المخازن تصاعدياً، ويُعرض الأقرب بشكل بارز مع المسافة بالكيلومتر.
6. إذا رفض العميل الإذن أو فشل التحديد: يظهر **dropdown** لاختيار المنطقة يدوياً.

---

## التشغيل المحلي

افتح `index.html` مباشرة في أي متصفّح حديث:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

> ملاحظة: بعض المتصفّحات تتطلّب **HTTPS** لـ Geolocation. التشغيل من الملف مباشرة (`file://`) يعمل على معظم المتصفّحات، لكن النشر على **GitHub Pages** يحلّ هذا تماماً.

---

## النشر على GitHub Pages

1. أنشئ مستودع جديد على GitHub باسم `nearest-store-finder` (أو أي اسم).
2. ارفع الملفات (الخطوات في قسم Git بالأسفل).
3. اذهب إلى: **Settings → Pages**.
4. تحت **Source** اختر: `Deploy from a branch`.
5. اختر `main` branch و مجلد `/ (root)` ثم احفظ.
6. انتظر دقيقة، وسيظهر لك الرابط:
   ```
   https://<username>.github.io/nearest-store-finder/
   ```

## ملاحظات الدمج لاحقاً في Magento

- استبدل المصفوفة `stores` بقائمة من **API الخاص بالمتجر** (مثلاً endpoint يرجع كل الفروع).
- أضف **حفظ المخزن المختار** في session/cookie حتى يبقى عند الانتقال بين الصفحات.
- اربط نتيجة الأقرب بـ **shipping module** في Magento لتحديد رسوم/مدة التوصيل تلقائياً.
- ضع منطق Haversine في ملف JS منفصل قابل للاستيراد، أو نفّذه في الـ backend (PHP) بدلاً من الـ frontend.
